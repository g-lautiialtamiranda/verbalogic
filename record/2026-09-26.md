# 2026-09-26

## Built
- Published the repo: one-click installer, MIT license, contributing guide, issue and PR templates.
- **U-02** Similar words: where Google has no synonyms in Spanish (or another non-English language), the column shows "Similar words", taken from the words Google translates back to (banco → orilla, ribera). Per meaning, only when there's evidence for that meaning. No extra requests.
- **U-03** Pronunciation: a speaker icon on each column, or Ctrl+Shift+1/2/3, plays Google's free text-to-speech through Windows. Clips are cached in `%APPDATA%\VerbaLogic\tts`.
- **U-04** Saved words and history: star a word (Ctrl+S) and open saved + recent lookups from the history icon, Ctrl+H or the tray. Stored in `history.sqlite`. Recent lookups are trimmed to 200 (`[history] size`), and saved words are kept forever.
- Start menu entry: VerbaLogic now adds itself to the Start menu. Searching for it or clicking a pinned icon opens the popup, starting the app if needed (`--open`).
- **F-05** Dictionary headword: the main word of each column is set in the Sitka serif, with its part of speech in small italics under it. Sentences stay in Segoe UI.
- **F-06** Translucent background: on Windows 11 the popup uses an acrylic backdrop (the desktop shows through, blurred), with Windows' own rounded corners and shadow. Off in Settings, or `[ui] backdrop = "none"`. The documented `DWMWA_SYSTEMBACKDROP_TYPE` only drew flat grey on this frameless popup, so it uses the accent-policy acrylic instead.
- **F-07** Formal palette: ink blue is the new default accent (the old purple default switches to it automatically), with deep teal, oxblood and graphite as presets, plus a warm "paper" theme. The accent is now kept for selection, focus, the active meaning and checked states.
- **F-08** Calm motion: the popup fades in and rises a few pixels, grey placeholder bars replace "…" and "Looking up synonyms…", and changing meaning cross-fades. All off when Windows' animation effects are off.
- **F-09** Fewer boxes: columns are split by a hairline and whitespace instead of bordered boxes, rewrites are plain rows, one set of radii (16/10/8) on an 8-px grid.
- **F-10** Logo: a bookplate-style seal (an italic Sitka "V" in ivory on a circle of the accent colour, with a hairline ring at larger sizes) for the tray, windows, Start menu, Startup and a taskbar pin, and in the popup header. It follows the accent: changing the colour redraws a multi-size .ico under a new name and re-points every VerbaLogic shortcut at it, so Windows doesn't keep showing a cached icon. Lighter on a dark taskbar. The README now opens with screenshots and a GIF of a lookup (`docs/`).
- **F-11** Settings like Windows 11: a sidebar (General, Languages, Appearance, Rewrites, History, About), grouped rows with a description each, a live preview under Appearance, and new History and About pages.
- Rewrites on OpenRouter only ever call free models (ids ending in `:free`), so the key can't spend credits even if the account has some.
- Meaning matching now treats "exclamation" and "interjection" as the same part of speech, and "¡Hola!" as "hola".
