# U-06 · Use AI to match translations to meanings (with an OpenRouter key)

**Status:** proposed  
**Effort:** M

## What
The meaning switcher picks the translation for each meaning with rules: which words it translates back to, and whether it shows up in the translated example or definition. It's right most of the time, but not always (for example, some Spanish meanings of "banco"). When an OpenRouter key is set, one short AI request could pick the right translation for each meaning, saved so it's only asked once per word.

## Why
More accurate translations per meaning, and nothing changes if you don't have a key.
