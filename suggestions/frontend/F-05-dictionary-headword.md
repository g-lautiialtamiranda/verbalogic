# F-05 · A headword like a printed dictionary

**Status:** proposed  
**Effort:** S

## What
Give the main word of each column the look of a dictionary entry: the word in a serif display face, with the part of speech and (with U-08) the pronunciation in small muted type right under it. Windows already ships **Sitka** (a serif by Matthew Carter, designed for screens, with optical sizes), so nothing needs to be bundled. The rest of the popup stays in Segoe UI, so the serif is used only for the headword.

## Why
It's the quickest way to make the popup look formal and "bookish" instead of like a generic app, and it puts the headword clearly above everything else.
